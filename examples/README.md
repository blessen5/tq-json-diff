# jdiff Examples

This directory contains sample JSON pairs demonstrating structural differences across various JSON data types.

## Sample Scenarios (Planned for Phase 2+)

- **`simple/`**: Key additions, removals, and primitive value updates.
- **`nested/`**: Deeply nested object hierarchy changes.
- **`arrays/`**: Element insertions, removals, and reordering.
- **`types/`**: Primitive type changes (e.g., string to number, object to array).
